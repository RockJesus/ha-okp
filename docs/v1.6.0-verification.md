## 功能说明（给用户的最终答案）

**本来就有、无需改动的**：
- 单账号多设备：v1.1.9 起每台机器人一个独立协调器 + 独立实体组
- 全机型：无 K5 白名单，实体按设备实际 dp 动态创建（K2/K3/K5/C5/L 系列同一套代码）
- 多家庭扫描

**v1.6.0 新增**：App 里新买/新分享一台机器人后，调用 `okp_cloud.rescan_devices` 即可接入，
不用输密码、不用重新验证。优先走 CoolKit 全量清单（含分享设备 itemType 2），失败回退 OKP 云端。

## 用法

开发者工具 → 动作 → `OKP Cloud: 重新扫描设备`。返回值里 `added` 是本次新发现的设备。
